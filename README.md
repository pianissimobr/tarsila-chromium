# Tarsila Chromium

Chromium otimizado para hardware ARM de baixo recurso. Inclui:
- Flags de runtime (jitless, processos, GPU, cache)
- Extensao Modo Cinema (video via mpv)
- Modo Leve (corta animacoes/sombras CSS)
- Bloqueio de anuncios DNR
- Otimizacao de imagens (lazy decode + menor srcset)

```
./build-deb.sh
```

Gera `tarsila-chromium_2.0.0_all.deb`.
